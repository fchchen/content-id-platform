Content ID Platform — Capability Report

.NET 8 API  ·  Go 1.23 worker  ·  SQS async processing  ·  SQL Server + MongoDB  ·  LocalStack  ·  OpenTelemetry  ·  GitHub Actions CI

End-to-End Flow

1. SubmitClient posts media metadata + fingerprint hash to .NET API.
2. PersistStored in SQL Server (state) and MongoDB (document).
3. QueueSQS receives job; DLQ retries on failure (max 3×).
4. MatchGo worker compares fingerprint against reference catalog.
5. ResultAPI returns match, confidence score, and rights policy.
