Content ID Platform Capability Report

Local demo stack showing .NET API intake, SQS-backed async processing, Go matching worker, PostgreSQL/MongoDB persistence, LocalStack AWS resources, and OpenTelemetry collection.

End-to-End Flow

1. SubmitClient posts media metadata and simulated fingerprint.
2. PersistAPI stores normalized state and fingerprint document.
3. QueueSQS receives an identification job with DLQ retry policy.
4. MatchGo worker compares against seeded reference assets.
5. ResultAPI returns match details and rights policy.
